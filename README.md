I’m a Security Engineer focused on **cloud security, DevSecOps, and secure AI applications**.

I build security controls and automation that help teams deploy safely, enforce least privilege, and investigate security events. My work spans AWS and Azure, infrastructure as code, CI/CD security, and security orchestration.

Added restricted tool execution, submission confirmation, a separate review workflow, and transactional audit records.
